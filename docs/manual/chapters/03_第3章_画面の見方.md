# 第3章 画面の見方

Workflow Studioにはたくさんのタブがありますが、最初から全部を覚える必要はありません。
この章では、それぞれのタブが「何をする場所か」をざっくりつかみ、
ComfyUI側に追加されるボタンとサイドパネルの役割を確認します。

---

## 3-1 タブの一覧と役割

Workflow Studioを開くと、画面の上部にタブが横一列に並んでいます。

左から順に、次のタブがあります。
「よく使う」に★が付いたタブから覚えていけば十分です。

| タブ（日本語表示） | 英語表示 | 何をする場所か | よく使う | 本書の章 |
| --- | --- | --- | :---: | --- |
| ワークフロー | Workflow | 保存したワークフローの一覧・整理 | ★ | 第4章 |
| ノード | Nodes | ノードの一覧・お気に入り登録 | | 第11章 |
| モデル | Models | Checkpoint・LoRAなどモデルの一覧・整理 | ★ | 第6章 |
| 生成UI | GenerateUI | ノード画面を触らずに画像を生成 | ★ | 第5章 |
| プロンプト | Prompt | プロンプトの保存・分類・AI補助 | ★ | 第7章 |
| ギャラリー | Gallery | 生成した画像の閲覧・設定の確認 | ★ | 第8章 |
| Image Edit | Image Edit | 画像の簡易編集・マスク作成 | | 第11章 |
| Video | Video | 動画生成・動画編集 | | 第11章 |
| Tagger | Tagger | 画像からタグ（プロンプト）を自動生成 | | 第11章 |
| 設定 | Settings | 言語・テーマ・フォルダなどの設定 | | 本章・第11章 |
| ヘルプ | Help | 機能一覧・ショートカット・トラブル対処 | | 本章 |
| AI TOOL | AI TOOL | ローカルAIによる翻訳・チャット・画像解析 | | 第10章 |

### タブは「整理する」「作る」「補助する」の3グループで考える
タブが多くて迷ったときは、次の3つのグループに分けて考えると分かりやすくなります。

- **整理する** － ワークフロー／ノード／モデル／プロンプト／ギャラリー
  手持ちの素材を一覧にして、探しやすくするタブです。
- **作る** － 生成UI／Image Edit／Video
  実際に画像や動画を作ったり、手を加えたりするタブです。
- **補助する** － AI TOOL／Tagger／設定／ヘルプ
  他のタブでの作業を助けたり、全体の設定をしたりするタブです。

> **ポイント**
> 各タブは互いにつながっています。
> たとえば、ワークフロータブで選んだワークフローを生成UIに読み込んだり、
> プロンプトタブで保存したプロンプトを生成UIで呼び出したりできます。

### ヘルプタブ
困ったときに最初に開きたいのが **ヘルプ** タブです。
左側に話題の一覧が並び、クリックすると右側に説明が表示されます。

- 機能一覧（タブごとの機能の概要）
- キーボードショートカット
- トラブルシューティング
- サポート（GitHubなどへのリンク）

本書を読みながら「このボタンは何だっけ？」と思ったときにも役立ちます。

## 3-2 ComfyUI側に追加されるボタン

Workflow Studioをインストールすると、ComfyUIの画面上部のメニューに **3つのボタン** が追加されます。

| ボタン | 名前 | 役割 |
| --- | --- | --- |
| ① W | Workflow Studioを開く | Workflow Studioを新しいタブで開きます。Shift＋クリックで新しいウィンドウ（第2章） |
| ② カメラ | キャンバススナップショット | いまのノード画面を画像として保存し、ワークフローのサムネイルにします（第4章） |
| ③ 四角が並んだアイコン | WS Library | ノード画面の横にサイドパネルを開閉します（3-3） |

ボタンにマウスを重ねると、英語で説明が表示されます。

> **ポイント**
> Workflow Studio本体（タブが並ぶ画面）と、ComfyUIのノード画面は **別のブラウザタブ** で開きます。
> 「整理や生成はWorkflow Studio」「細かい組み立てはComfyUIのノード画面」と使い分け、
> 2つの画面を行き来しながら使うのが基本のスタイルです。

---

## 3-3 サイドパネル「WS Library」

③のボタンを押すと、ComfyUIのノード画面の横に **WS Library（Workflow Studio Library）** というパネルが開きます。

WS Libraryは、**Workflow Studioで整理した素材を、ノード画面ですぐ使うための棚** です。
パネルの上部には、1文字のタブが並んでいます（マウスを重ねると正式な名前が表示されます）。

| タブ | 名前 | できること |
| --- | --- | --- |
| W | Workflows | ワークフローをドラッグしてキャンバスに読み込む |
| N | Nodes | お気に入りのノードやノードセットをキャンバスに置く |
| P | Prompts | 保存したプロンプトをキャンバスに置く・コピーする |
| M | Models | モデルをドラッグして、読み込み用のノードごとキャンバスに置く |
| I | Information | 画像やワークフローのファイルを落として、中身（使ったモデルやプロンプト）を調べる |
| A | AI TOOL | 翻訳やチャットなどのAI機能を、ノード画面のまま使う |

たとえば M タブからモデルをキャンバスへドラッグすると、そのモデルを読み込むノードが自動で配置されます。
ノードを一覧から探して置いて、ファイル名を選んで……という手間が省けます。

詳しい使い方は第9章で説明します。今は「ノード画面の横に、素材の棚を出せる」とだけ覚えておけば大丈夫です。

## 3-4 テーマと見た目の設定

Workflow Studioの見た目は、**設定** タブで好みに合わせて変えられます。
長時間使う道具なので、目が疲れにくい配色や読みやすい文字サイズにしておくのがおすすめです。

### テーマ
**「テーマ」** の欄から、画面全体の配色を選べます。標準は暗い配色の「Deep Ocean Dark」です。

| テーマの例 | 雰囲気 |
| --- | --- |
| Deep Ocean Dark（デフォルト） | 暗めの青。画像が見やすい |
| Light Minimalist（クリーン） | 白基調で明るくシンプル |
| Pastel Dream（パステル） | やわらかいパステル調 |
| Corporate Trust（企業向け） | 落ち着いた白と青 |

このほか、ポップ調・サイバーパンク・レトロなど、全部で13種類のテーマがあります。

> **ポイント**
> 生成した画像の色を確認するときは、暗めのテーマのほうが色を見分けやすくなります。
> 迷ったら、まずはデフォルトのまま使ってみましょう。

### カスタマイズ
**「カスタマイズ」** を開くと、選んだテーマをさらに細かく調整できます。

- **カラー調整** － 背景・テキスト・アクセントなどの色を個別に変更
- **背景パターン** － ストライプやドットなどの模様を背景に追加
- **フォント** － 文字の書体を変更（Zen丸ゴシック、BIZ UDPゴシックなど日本語フォントも選べます）

調整が終わったら **「適用して保存」** を押します。
元に戻したいときは **「カスタマイズをリセット」** を押します。

### 文字サイズ
**「文字サイズ」** の欄で、画面全体の文字の大きさを変えられます。
文字が小さくて読みにくいと感じたら、ここで大きくしましょう。

### WS Libraryの見た目
WS Library（3-3）の配色は、パネル内の **歯車ボタン**から別に設定できます。
ComfyUIの画面の色に合わせて、背景や文字の色を調整できます。

> **この章のまとめ**
> - タブは「整理する」「作る」「補助する」の3グループで考えると分かりやすい
> - まずはワークフロー・モデル・生成UI・プロンプト・ギャラリーの5つを覚えれば十分
> - ComfyUIの上部には「W」「カメラ」「WS Library」の3つのボタンが追加される
> - WS Libraryは、ノード画面の横に出せる素材の棚
> - 見た目は設定タブのテーマ・カスタマイズ・文字サイズで調整できる
