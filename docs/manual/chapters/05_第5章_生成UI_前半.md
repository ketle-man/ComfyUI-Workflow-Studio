# 第5章 生成UIタブ － ノードを触らずに画像を作る

いよいよ、Workflow Studioで画像を生成します。
**生成UI（GenerateUI）** タブは、ワークフローの中から「プロンプト」「モデル」「サイズ」など
よく変える項目だけを取り出して、入力フォームとして表示してくれる画面です。
ノードを探して線をたどる必要はありません。

この章の前半（5-1〜5-4）では、第4章で取り込んだ基本のサンプルを使って、はじめての1枚を生成します。

> **事前に準備しておくもの**
> - ComfyUIが起動していること
> - Checkpointモデルが1つ以上、ComfyUIの `models/checkpoints` フォルダに入っていること
> - 第4章で、サンプルワークフロー（`ws_sdxl_t2i_basic` など）を取り込んでいること

---

## 5-1 ワークフローを生成UIに読み込む

1. **ワークフロー** タブを開きます。
2. 使いたいワークフロー（例：`ws_sdxl_t2i_basic`）を **クリック** して選択します。
3. サイドパネルの **GenerateUIチェック**（第4章 4-7）で、「変換」が ○ になっていることを確認します。
4. ツールバーの **「生成UIに読み込み」** を押します。

自動で **生成UI** タブに切り替わり、ワークフローの内容が読み込まれます。
画面上部に、読み込んだワークフローの名前が表示されていれば成功です。

> **ポイント**
> 生成UIの画面は、ボタンや項目名の多くが英語のまま表示されます。
> 本書では、英語の表示名をそのまま使い、必要に応じて意味を添えて説明します。

---

## 5-2 生成UIの画面の見方

生成UIタブは、大きく次の部分に分かれています。

| 番号 | 場所 | 役割 |
| --- | --- | --- |
| ① | 上部のバー | ComfyUIとの接続状態、ワークフロー名、各種ボタン |
| ② | サブタブ | Input／Model／Settings／Feeder／Batch／Lab の切り替え |
| ③ | 編集エリア（中央） | 選んだサブタブの設定項目 |
| ④ | Raw JSON（右側） | ワークフローの中身をJSONで表示（上級者向け） |
| ⑤ | 生成パネル | Generateボタン、進み具合、シード設定、生成結果 |

### ① 上部のバー
| 表示・ボタン | 意味 |
| --- | --- |
| Connected／Disconnected | ComfyUIとつながっているか。緑の **Connected** なら生成できます |
| Connect | ComfyUIに接続し直す |
| Refresh Models | モデルの一覧を読み込み直す（ComfyUIにモデルを追加したあとに押す） |
| Reset Workflow | 編集した内容を捨てて、ワークフローを読み込んだ直後の状態に戻す |
| ワークフロー名 | いま読み込んでいるワークフロー |

> **ポイント**
> 生成UIタブを開くと、ComfyUIへの接続は自動で行われます。
> **Disconnected** と表示されている場合は、ComfyUIが起動しているか確認して **Connect** を押してください。

### ② サブタブ
| サブタブ | 何を設定するか | 本書 |
| --- | --- | --- |
| Input | プロンプト、入力画像 | 5-3 |
| Model | Checkpoint・VAE・LoRAなどのモデル | 5-3 |
| Settings | シード・ステップ数・サンプラー・画像サイズなど | 5-4 |
| Feeder | フォルダの画像を順番に処理する | 5-6 |
| Batch | 条件を変えながらまとめて生成する | 5-5 |
| Lab | 実験的なI2Iバッチ生成（上級） | 5-7 |

まずは **Input・Model・Settings** の3つだけ覚えれば十分です。

### ④ Raw JSON
Input・Model・Settingsの右側には、ワークフローの中身がJSON形式で表示されます。
フォームで値を変えると、ここにも反映されます。
慣れないうちは、ここは「見るだけ」にしておきましょう。

## 5-3 はじめての1枚を生成する

いよいよ生成です。最低限、次の3つを確認・設定します。

1. どのモデルで描くか（Model）
2. 何を描くか（Input → Prompt）
3. 生成する（Generate）

### 手順1：モデルを選ぶ（Model）
1. サブタブの **Model** を開きます。
2. **Checkpoint** の欄で、手元にあるモデルを選びます。
   一覧が長い場合は、欄の上の入力欄に文字を入れると絞り込めます。
3. 欄の下にある **Apply** ボタンを押します。

> **ポイント：モデルが見つからないとき**
> ワークフローに保存されているモデルが、あなたのパソコンに入っていないことがあります。
> 配布されているワークフローを使うときは、ほぼ必ず起こります。次のどちらかの形で知らせてくれます。
> - 欄に「△ （モデル名）（見つかりません）」と表示される
> - 読み込んだときに「このワークフローのCheckpoint「…」が見つからず、無警告で別のモデルに差し替えられました」と表示される
>   （この場合、手元のモデルの一覧の先頭のものに自動で差し替わっています）
>
> どちらの場合も、一覧から使いたいモデルを選び直して、Apply を押してください。
> 毎回選び直すのが面倒なときは、設定タブの **デフォルトCheckpoint**（第11章）が便利です。

> **注意：Applyを押し忘れない**
> 生成UIでは、モデルやSettings（5-4）の値を変えたあと **Apply** ボタンを押して、はじめてワークフローに反映されます。
> Applyを押さずにGenerateすると、**変更前の値のまま** 生成されてしまいます。
> 「設定を変えたのに結果が変わらない」ときは、まずApplyの押し忘れを疑いましょう。
> （プロンプトの入力欄だけは、Generateを押したときに自動で反映されます）

> **ポイント**
> 項目名が明るい緑色で表示されているのは、読み込んだワークフローにそのモデルのノードが含まれている項目です。
> 緑色でない項目は、変更してもこのワークフローには影響しません。

### 手順2：プロンプトを書く（Input）
1. サブタブの **Input** を開き、その中の **Prompt** を選びます。
2. **Positive Prompt** の欄に、描いてほしい内容を英語で入力します。

   ```
   a cute cat sitting on a windowsill, sunlight, soft colors, high quality
   ```

3. **Positive Prompt** の **Apply** を押します。
4. 必要に応じて **Negative Prompt** の欄に、描いてほしくない内容を入力し、こちらも **Apply** を押します。

> プロンプトは、Applyを押し忘れてもGenerateを押したときに自動で反映されます。
> ただし、Raw JSON（右側）で反映結果を確かめられるので、Applyを押す習慣をつけておくと安心です。

   ```
   low quality, blurry, bad anatomy
   ```

> **ポイント**
> Apply の横にある **↺（戻す）** ボタンを押すと、入力欄の内容を、いまワークフローに反映されている値に戻せます。
> 書き換えに失敗したときに便利です。

> **ポイント**
> 英語が苦手な方は、第7章・第10章で紹介するAI翻訳機能を使うと、日本語で考えたプロンプトを英語にできます。

### 手順3：生成する（Generate）
1. 画面の生成パネルにある **Generate** ボタンを押します。
2. 進み具合を表すバーが伸びていき、パーセントが表示されます。
3. 「Done」と表示されると、生成された画像が生成パネルに表示されます。

おめでとうございます。これで、Workflow Studioではじめての1枚が完成しました。

生成した画像は、ComfyUIで生成した場合と同じく、ComfyUIの `output` フォルダに保存されます。
あとから見返したいときは、**ギャラリー** タブ（第8章）で一覧できます。

> **ポイント：途中で止めたいとき**
> 生成中は、Generateボタンの横に **Stop** ボタンが表示されます。押すと生成を中断します。

> **ポイント：ApplyとGenerateを一度に**
> **Alt キーを押しながら Apply** をクリックすると、値の反映と生成を一度に行えます。
> 慣れてきたら、プロンプトを書き換えて Alt＋Apply、という流れで手早く試せます。

### 生成したワークフローを保存する
生成UIで変えた設定を、あとでまた使いたいときは、サブタブの右端にある **Save** ボタンを押します。
名前を付けて保存すると、ワークフロータブに新しいワークフローとして追加されます。

## 5-4 シード・サンプラー・ステップ数の意味

1枚目が生成できたら、次は **Settings** サブタブで、画像の仕上がりを左右する設定を見てみましょう。

Settingsタブは、左右2つのブロックに分かれています。

- **KSampler（左）** － 画像をどのように描くかの設定
- **Latent Image（右）** － 画像の大きさと枚数の設定

ここでも、値を変えたら各ブロックの **Apply** を押すのを忘れないようにしましょう。

### KSampler の項目
| 項目 | 意味 | 初心者向けの目安 |
| --- | --- | --- |
| Seed（シード） | 画像のもとになる「乱数の種」。同じ設定・同じシードなら、ほぼ同じ画像になる | 生成時は生成パネルのシード設定（下記）が優先されるので、ここは「読み込んだワークフローのシードの確認用」と考える。ワークフローのシードをそのまま使いたいときは、生成パネルのモードを **Workflow** にする |
| Steps（ステップ数） | 描き込みを何回くり返すか。多いほど丁寧だが時間がかかる | 20〜30 |
| CFG | プロンプトにどれだけ忠実に従うか。高すぎると色や形が崩れやすい | SDXLなら5〜8程度 |
| Sampler（サンプラー） | 描き方のアルゴリズム | `euler`、`dpmpp_2m` など |
| Scheduler（スケジューラー） | ステップごとの描き込み量の配分 | `normal`、`karras` など |
| Denoise | 元の画像をどれだけ描き変えるか。文章から作る場合は 1.0 | 1.0（画像から作る場合は 0.4〜0.7 など） |

> **ポイント**
> 目安の値はモデルによって異なります。モデルの配布ページ（Civitaiなど）に推奨値が書かれていることが多いので、確認してみましょう。
> 迷ったら、サンプルワークフローに最初から入っている値のまま使えば大丈夫です。

### Latent Image の項目
| 項目 | 意味 | 目安 |
| --- | --- | --- |
| Width（幅） | 画像の横の大きさ（ピクセル） | SDXLなら1024前後、SD1.5なら512前後 |
| Height（高さ） | 画像の縦の大きさ（ピクセル） | 同上 |
| Batch Size | 1回の生成で何枚作るか | 1〜4（多いほどメモリを使う） |

> **注意**
> モデルが学習したサイズから大きく外れると、人物が二重になったり、構図が崩れたりしやすくなります。
> 縦長・横長にしたいときも、合計のピクセル数がおおよそ同じになるように調整しましょう（例：SDXLなら 832×1216 など）。

### シードの管理（生成パネル）
シードは、生成パネルの **Seed** 欄と、その下のプルダウンで管理します。

| モード | 動き | 使いどころ |
| --- | --- | --- |
| Random | 毎回ランダムなシードで生成 | いろいろな絵を試したいとき |
| Fixed | Seed欄の値で固定 | 気に入った絵をもとに、プロンプトだけ変えて比べたいとき |
| Increment | 生成するたびに1ずつ増やす | 少しずつ違う絵を順番に作りたいとき |
| Decrement | 生成するたびに1ずつ減らす | Incrementの逆 |
| Workflow | ワークフローに入っているシードを、上書きせずそのまま使う | ギャラリーから読み込んだ画像や、配布されたワークフローを、元のシードで再現したいとき |

生成が終わると、Seed欄には **実際に使われたシード値** が表示されます。

> **ポイント：Workflowモード（v0.8.3〜）**
> モードを **Workflow** にすると、Seed欄の値やランダムではなく、読み込んだワークフロー自身のシードで生成します。
> Randomで何枚か試したあとでも、ワークフロー本来のシード（読み込んだ時点の値）に戻って生成されます。
> ワークフローにシードの入力が見つからない場合は、Seed欄の値（−1ならランダム）が使われます。
> 同じシードと同じ設定で続けて2回押すと、ComfyUIは計算済みの結果を再利用するため、新しい画像は増えません（故障ではありません）。

### 気に入った絵を「育てる」流れ
シードを使うと、気に入った1枚をもとに少しずつ改良できます。

1. **Random** で何枚か生成し、気に入った構図の絵を探す
2. 気に入った絵が出たら、モードを **Fixed** に切り替える（Seed欄にはその絵のシードが入っています）
3. プロンプトに言葉を足したり、Stepsを変えたりして、違いを比べる

シードを固定すると、「何を変えたら、どう変わったか」が分かりやすくなります。
これは、画像生成に慣れるためのいちばんの近道です。

> **この章（前半）のまとめ**
> - ワークフロータブで選んで「生成UIに読み込み」を押すと、生成UIで編集できる
> - 基本は Input（プロンプト）・Model（モデル）・Settings（細かい設定）の3つのサブタブ
> - モデルやSettingsの値を変えたら必ず **Apply**。押し忘れると変更前の値で生成される（プロンプトは自動で反映）
> - Generate で生成。Alt＋Apply なら反映と生成を一度に行える
> - シードを Fixed にすると、気に入った絵をもとに条件を変えて比べられる。ワークフローのシードをそのまま使うなら Workflow
