## 付録B キーボード・マウス操作

### 全体
| 操作 | 動き |
| --- | --- |
| Esc | 開いている画面（モーダル・パネル）を閉じる |
| Enter | 名前の変更を確定する／チャットを送信する |
| Shift＋Enter | チャットで改行する |
| ダブルクリック | 詳細画面を開く（ワークフロー・モデルなど） |
| Shift＋クリック（Wボタン） | Workflow Studioを新しいウィンドウで開く |

### 生成UI
| 操作 | 動き |
| --- | --- |
| Alt＋クリック（Apply） | 値の反映と生成を一度に行う |
| Ctrl＋↑／↓（プロンプト入力欄） | 選んだ言葉の強調 `(言葉:数値)` を0.05ずつ増減する |
| Enter／Shift＋Enter（Raw JSONの検索欄） | 次の一致／前の一致へ移動する |

### ギャラリー
| 操作 | 動き |
| --- | --- |
| Ctrl＋クリック | 複数の画像を選ぶ |
| Alt＋クリック | 画像をメタデータサブタブで開く |
| Enter（意味検索がオンのとき） | 検索欄の文章で意味検索を実行する |

### WS Library
| 操作 | 動き |
| --- | --- |
| ドラッグ＆ドロップ | キャンバスのドロップした位置に置く・読み込む |
| ダブルクリック | キャンバスの中央付近に置く・読み込む |
| Alt＋クリック（Nタブ） | ノードのお気に入りをオン／オフする |

### Image Edit
| 操作 | 動き |
| --- | --- |
| V／B／T／S／G | Select／Draw／Text／Shape／Fill ツールに切り替え |
| Ctrl＋Z／Ctrl＋Y | 元に戻す／やり直す |
| マウスホイール | 拡大・縮小 |
| Space＋ドラッグ | 表示位置を移動する |
| Delete | 選んでいるレイヤーを削除する（レイヤーが2つ以上あるとき） |
