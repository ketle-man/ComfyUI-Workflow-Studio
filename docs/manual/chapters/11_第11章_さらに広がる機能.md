# 第11章 さらに広がる機能（紹介編）

ここまでで、Workflow Studioの基本的な使い方はひととおり身につきました。
この章では、まだ紹介していないタブや機能を、**どんなことができるか** を中心に紹介します。
すべてを今すぐ使う必要はありません。「こんなこともできるんだ」と頭の片隅に置いておき、
必要になったときに試してみてください。

---

## 11-1 ノードタブ － インストール済みのノードを一覧する

**ノード（Nodes）** タブでは、ComfyUIにインストールされているすべてのノードを一覧できます。

- **検索・絞り込み** － 名前、カテゴリー、パッケージ（どのカスタムノードに含まれるか）で絞り込めます。数千個あっても、一覧が先に表示されて検索も軽く動きます（v0.8.0〜）。
- **詳細パネル** － ノードを選ぶと、入力と出力の種類（I/O仕様）を確認できます。
- **お気に入り・グループ・タグ** － よく使うノードを整理できます。

ここでお気に入りやグループに登録したノードは、WS Libraryの **N** タブに表示され、
ノード画面へドラッグで置けるようになります（第9章）。

> **こんなときに**
> 「カスタムノードを入れたけど、どんなノードが増えたのか分からない」
> → **パッケージ** で絞り込むと、そのカスタムノードに含まれるノードの一覧が見られます。

## 11-2 Tagger － 画像からタグを自動で作る

**Tagger** タブは、画像を読み取って、その画像を表すタグ（`1girl, long hair, smile` など）を自動で作る機能です。
アニメ系のモデルのプロンプト作りや、学習用画像のタグ付けに使えます。

### 3つのサブタブ
| サブタブ | できること |
| --- | --- |
| Single | 1枚の画像からタグを作る |
| Batch | フォルダ内の画像に、まとめてタグを付ける（画像と同じ名前の `.txt` ファイルを書き出すことも可能） |
| DB | タグを付けた画像の記録を検索・編集する |

### 使い方（Single）
1. 画像を、プレビュー部分にドロップします（ギャラリーの詳細パネルの **Tagger** ボタンからも開けます）。
2. 使うモデルを選び、実行ボタンを押してタグを作ります。
3. 結果を使います。

   | ボタン | 動き |
   | --- | --- |
   | GenUI:P | 生成UIのポジティブプロンプトに追加する |
   | Send to Prompt | プロンプトタブのポジティブプロンプトに追加する |

**しきい値** のスライダーで、どのくらい確かなタグまで出すかを調整できます。
数値を上げるとタグは少なく確かなものだけに、下げると多くなります。

### 準備が必要
Taggerを使うには、次の準備が必要です。

1. **タグ付け用のモデル**（WD Tagger など）を、ComfyUIの `models/tagger/（モデル名）/` フォルダに置きます。
   フォルダには、`.onnx` ファイルと `selected_tags.csv` を入れます。
2. **追加のPythonパッケージ** をインストールします。
   Workflow Studioのフォルダにある `requirements.txt` を使います。

   ```
   （ComfyUIのPython） -m pip install -r requirements.txt
   ```

   「ComfyUIのPython」の場所は環境によって違います。第2章 2-6 の表で確認してください
   （例：Windowsのポータブル版では `python_embeded` フォルダの中の `python.exe`）。

> **注意**
> パソコンにもともと入っているPythonにインストールしても、ComfyUIからは使えません。
> 必ず、**ComfyUIが使っているPython** にインストールしてください。
> 分からない場合は、ComfyUI Managerの機能でパッケージをインストールする方法もあります。

> **ポイント**
> ローカルAI（第10章）の画像読み取り（VLM）と組み合わせて、両方の結果をまとめたタグを作ることもできます。

## 11-3 Image Edit － 生成した画像にちょっと手を加える

**Image Edit** タブは、レイヤー機能を持った簡易画像編集ツールです。
生成した画像に文字を入れたり、一部を描き直すためのマスクを作ったりできます。

### 主な機能
| ツール | できること |
| --- | --- |
| Select | レイヤーの移動・拡大縮小・回転 |
| Draw | ペンで描く（ペンタブレットの筆圧にも対応） |
| Text | 文字を入れる |
| Shape | 四角・丸・線を描く |
| Fill | 塗りつぶし・グラデーション |
| Mask | 描き直したい部分を指定する（マスク作成） |
| Blur | ぼかし・モザイク |
| BG Remove | 背景を消す |
| Inpaint | マスクした部分を、生成UIのワークフローで描き直す |

- 画像は、ドラッグ＆ドロップ、**File Open**、またはギャラリーの **Image Edit** ボタンで開きます。
- 編集した画像は、**Save PNG**（ダウンロード）、**Save to Gallery**（ギャラリーに保存）などで保存します。
- **Ctrl＋Z** で元に戻す、**Ctrl＋Y** でやり直しができます。

### インペイント（部分の描き直し）
Image Editのいちばん便利な使い方が、**インペイント** です。
「顔だけ描き直したい」「手が崩れたところだけ直したい」というときに使います。

1. 生成UIに、インペイント用のワークフロー（付属サンプルの `ws_inpaint_basic` など）を読み込みます。
2. Image Editで画像を開き、**Mask** で描き直したい部分を塗ります。
3. **Inpaint** ツールで実行すると、塗った部分だけが描き直されます。

> **ポイント**
> 背景を消す機能の高品質版や、より高度なマスク機能を使うには、
> 作者の別のカスタムノード **comfyui-mask-editor-one** が必要です。
> PSD形式での保存・読み込みには、追加のPythonパッケージ（psd-tools）が必要です。

## 11-4 Video － 動画を作る・つなぐ

**Video** タブは、動画生成モデルを使って、画像や文章から短い動画を作るための専用画面です。

### 対応している動画生成モデル
- **MiniMax H3**（画像から動画）
- **LTX-2.5**（文章から動画、画像から動画、最初と最後の画像を指定して動画）
- **Wan2.2**（文章から動画）

対応するワークフローを、ワークフロータブの **Videoに読み込み** で読み込んで使います（第4章 4-6）。

### 主な機能
| サブタブ | できること |
| --- | --- |
| Plan | 動画を「ブロック」に分け、ブロックごとにプロンプト・長さ・最初／最後の画像を決めて、順番に生成する |
| Edit | 生成した動画や画像を並べて、切り取り・つなぎ合わせ・文字入れ・BGM付けをして書き出す |
| Asset | 生成した動画や画像、音声を一覧する。音声は「BGMに設定」や「サウンドとして追加」ができる（種類フィルタの Audio Only で音声だけ表示） |

そのほか、動画の好きな場面を静止画として保存する **Frame** や、動画をGIFアニメに変換する **GIF** の機能もあります。

> **注意**
> 動画生成は、画像生成よりもはるかに多くのGPUメモリと時間を使います。
> 使うモデルの必要スペックを確認してから試しましょう。

## 11-5 設定タブの主な項目

**設定** タブでは、Workflow Studio全体の設定をします。
項目ごとに折りたたまれているので、見出しをクリックして開きます。
ここでは、これまでの章で紹介していない項目を中心に紹介します。

| 項目 | 内容 | 関連する章 |
| --- | --- | --- |
| テーマ | 画面の配色・フォント | 第3章 |
| UI言語／要約言語 | 表示言語 | 第2章 |
| 文字サイズ | プロンプト入力欄などの文字の大きさ | 第3章 |
| ワークフローデータフォルダ | ワークフローを読み込むフォルダ | 第4章 |
| ギャラリー Outputフォルダ | ギャラリーで表示するフォルダ | 第8章 |
| デフォルトワークフロー | Workflow Studioを開いたとき、生成UIに自動で読み込むワークフロー | 下記 |
| デフォルトCheckpoint | 生成UIにワークフローを読み込むとき、モデルを自動で差し替える | 下記 |
| CivitAI APIキー | Civitaiの情報取得用（省略可） | 第6章 |
| Eagle 連携 (オプション) | 生成画像をEagleに自動保存 | 第8章 |
| VRAM調整（Ollama） | 生成前にAIモデルをメモリから降ろす | 第10章 |
| データ管理 | 設定やデータのバックアップ・復元 | 下記 |

### デフォルトワークフロー
いつも使う基本のワークフローを設定しておくと、Workflow Studioを開いたときに生成UIへ自動で読み込まれます。
ワークフロータブの詳細画面の **デフォルトに設定** ボタンからも設定できます。

### デフォルトCheckpoint
ネットから入手したワークフローには、手元にないモデルが指定されていることがよくあります（第5章 5-3）。
**デフォルトCheckpoint** を設定してオンにしておくと、生成UIにワークフローを読み込むたびに、
Checkpointが自動で指定のモデルに差し替わります。モデルの選び直しの手間が省けます。

### データ管理（バックアップ）
**データ管理** では、Workflow Studioで整理した情報（お気に入り・バッジ・グループ・プリセットなど）を
ファイルに書き出したり（エクスポート）、読み込んで元に戻したり（インポート）できます。

**フルバックアップ (ZIP)** を使うと、スタイルやLabのプランなどのフォルダ単位のデータも含めて、まとめてバックアップできます。

> **ポイント**
> パソコンの買い替えやComfyUIの入れ直しの前には、必ずバックアップを取っておきましょう。
> 時間をかけて整理した情報を、そのまま新しい環境に引き継げます。
> （安全のため、APIキーはバックアップに含まれません）

## 11-6 連携ソフト：ComfyUI Comic Creator － 生成した画像でマンガを作る

**ComfyUI Comic Creator**（以下、Comic Creator）は、Workflow Studioと同じ作者が開発している、
ComfyUI上で動く **マンガ制作用** のカスタムノードです。
Workflow Studioとは別にインストールするソフトですが、両方を入れると連携して使えます。

### Comic Creatorでできること
| 機能 | 内容 |
| --- | --- |
| コマ割り | テンプレートを選んで、ページにコマを作る（自作テンプレートも登録可能） |
| 画像の配置 | コマに画像をドラッグ＆ドロップで配置する |
| フキダシ・テキスト | 縦書き・横書きのセリフ、さまざまな形のフキダシ、効果文字を入れる |
| マンガ効果 | 集中線・スクリーントーン・網点（ハーフトーン）などを加える |
| 画像の編集 | レイヤー付きの画像編集（Image タブ） |
| AIでの自動作成 | お題から、ストーリー・脚本・コマ割りをAIで下書きする（Auto タブ） |
| 書き出し | JPEG／PNG／WebP／SVG／PDF／**EPUB** 形式で出力する |

### Workflow Studioとの連携
両方をインストールすると、次のような連携ができます。

- **Comic Creatorの中でWorkflow Studioのギャラリーを使う**
  Comic Creatorの中にWorkflow Studioのギャラリーが表示され、生成した画像を選んで **Send CC** ボタンでコマに送れます。
  （Send CCボタンは、Comic Creatorの中で開いたギャラリーにだけ表示されます）
- **Comic Creatorから画像を生成する**
  Comic Creatorの画面から、Workflow Studio（生成UI）を通して、コマに入れる画像を生成したり（T2I）、
  描いたラフや配置した画像をもとに描き直したり（I2I・インペイント）できます。

「Workflow Studioで画像を作る → Comic Creatorでマンガにまとめる」という流れで、
画像生成からマンガの完成までを、ComfyUIの中だけで行えます。

### インストールと起動
1. ComfyUI Managerの **Install via Git URL** に、次のURLを入力してインストールします。

   ```
   https://github.com/ketle-man/comfyui-comic-creator
   ```

   （手動の場合は、Workflow Studioと同じく `ComfyUI/custom_nodes/` に `git clone` します）

2. ComfyUIを再起動します。
3. ComfyUIの上部メニューに追加された **CC** ボタンを押すと、Comic Creatorが新しいタブで開きます。

> **ポイント**
> Comic Creatorの詳しい使い方は、アプリ内の **ヘルプ** タブ（日本語対応・検索機能あり）を参照してください。

> **この章のまとめ**
> - ノードタブでインストール済みのノードを一覧・整理でき、WS Libraryで使える
> - Taggerは画像からタグを自動生成する。モデルと追加パッケージの準備が必要
> - Image Editはレイヤー付きの簡易編集ツール。インペイントで部分的な描き直しもできる
> - Videoタブで、対応する動画生成モデルを使った動画作りと簡単な編集ができる
> - 設定タブの「デフォルトCheckpoint」と「データ管理（バックアップ）」は特に便利
> - 同じ作者の Comic Creator と組み合わせると、生成した画像でマンガを作れる
